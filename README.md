# SIPOL — Sistema Integrado de Polícia

**DECAR / PCGO — Delegacia Especializada em Repressão a Crimes de Furto e Roubo de Cargas**

Sistema offline de gestão de inteligência policial.  
Desenvolvido para uso interno da DECAR/PCGO.

---

## Download do Instalador

Acesse a aba **[Releases](../../releases)** e baixe o arquivo `SIPOL-Instalador-v1.0.0.exe`.

## Funcionalidades

- Cadastro e gestão de investigados
- Relatório de investigado (ficha completa + impressão)
- Controle de operadores com 4 níveis de acesso
- Sistema de solicitações de acesso
- Log de auditoria
- Configuração da instituição
- Backup e restauração local
- 100% offline — dados salvos no computador
